# Word swaps

The ASD-STE100 Dictionary holds roughly 900 approved words, each with one approved part of speech and one approved meaning. The official dictionary is the authority and is free on request from asd-ste100.org. This file covers the swaps that come up constantly in product and marketing copy.

| perform, execute, conduct | do |
| commence, initiate, launch (a process) | start |
| terminate, cease, halt | stop |
| obtain, acquire, procure | get |
| provide, deliver (a capability) | give |
| assist, aid, facilitate | help |
| require, necessitate | need |
| indicate, display, illustrate | show |
| modify, alter, adjust | change |
| maintain (a state) | keep |
| locate, identify (a thing) | find |
| attempt, endeavor | try |
| permit, allow, enable | let |
| purchase | buy |
| request | ask |
| transmit, forward | send |
| examine, inspect | check, examine (both approved; pick one and keep it) |
| leverage, harness, unlock, empower | rewrite the sentence — none of these are actions |
| accommodate | hold, fit |
| implement | do, install, add |
| eliminate | remove |
| replicate | copy |
| monitor (as verb) | watch, look at |
| approximate (as verb) | rewrite |

## 3. Quantity and degree

| Instead of | Use |
|---|---|
| approximately, circa | about |
| sufficient, adequate | enough |
| excessive | too much |
| numerous, multiple, a multitude of | many, or the number |
| a minimum of | at least |
| the majority of | most |
| a variety of, a range of | different, or list them |
| substantially, significantly | give the number |
| virtually, essentially | almost |
| optimal, optimum | best |
| minimal | small, or the number |

Prefer the number over any of these. "Up to 40% faster" beats "significantly faster". "40 channels" beats "numerous channels".

## 5. Banned marketing vocabulary

These fail STE and they fail the reader. They say nothing, so the reader supplies nothing.

seamless, seamlessly, frictionless, effortless, robust, powerful, cutting-edge,
state-of-the-art, best-in-class, world-class, industry-leading, next-generation,
revolutionary, game-changing, disruptive, innovative, transformative, unparalleled,
turnkey, holistic, synergy, scalable (unless you give the number), enterprise-grade,
military-grade, blazing-fast, lightning-fast, AI-powered (unless the AI is the product),
supercharge, turbocharge, unlock, unleash, empower, elevate, reimagine, redefine,
craft (as verb), delight (as verb), obsess, journey (non-literal), magic, magical,
simply, just, easily, effortlessly

Two tests. If a competitor could paste the sentence onto their own page unchanged, delete it. If deleting the adjective changes nothing, delete the adjective.

Replace with: a number, a named outcome, or the thing the reader no longer has to do.

## 6. Hedges and filler

Delete on sight: very, really, quite, rather, fairly, somewhat, actually, basically, essentially, literally, obviously, clearly, of course, needless to say, that being said, at the end of the day, when it comes to, in terms of, the fact that.

"We help you to more easily manage your properties" → "You manage your properties in one place."

## 7. Modals

| Meaning | Use |
|---|---|
| Ability or possibility | can |
| Mandatory | must |
| Recommended | we recommend that you... |
| Prohibited | do not |
| Future fact | will |

Avoid "shall", "should" (ambiguous between advice and obligation), "may" (ambiguous between permission and possibility), and "might".

## 8. Words that look banned but are fine

Keep technical names as they are. "Rate plan", "channel manager", "booking engine", "webhook", "API key", "flat config" are names of things, not jargon, and inventing synonyms for them breaks rule one. Define each once, then use it identically forever.

Also fine: short Anglo-Saxon verbs that feel too plain (get, do, put, make, keep, let, show, tell). Plain is the point.
